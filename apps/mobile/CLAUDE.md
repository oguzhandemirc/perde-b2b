# apps/mobile

Expo (React Native, TypeScript) mobil uygulaması. Sorumlu: Oğuzhan.

Expo'nun resmi yönergeleri: @AGENTS.md

Proje kuralları kökteki `CLAUDE.md` ve `.claude/rules/` altındadır (`mobile/react-native.md`, `mobile/mock-data.md` bu klasörde otomatik devreye girer).

Komutlar (kökten):

```bash
pnpm mobile                          # geliştirme sunucusu
pnpm --filter @b2b/mobile lint
pnpm --filter @b2b/mobile typecheck
```
